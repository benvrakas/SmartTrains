# SHORT DESCRIPTION

Trains without fixed timetables: platforms say what they supply and need, and managed trains are sent where it's needed.

# FULL DESCRIPTION

In FullDescription.md.

# NETWORK ACTIVITY TRANSPARENCY

SmartTrains doesn't connect to the internet. In multiplayer, players send their setting changes to the host and the
host sends readouts back through the game's own connection. There's no telemetry or analytics.
